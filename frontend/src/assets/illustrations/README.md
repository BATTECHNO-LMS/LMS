# Illustrations

Design-system status and marketing visuals live in existing asset folders — **do not duplicate binaries here**.

## Reuse these paths

| Path | Use |
|------|-----|
| `src/assets/images/` | Product/status SVGs and brand logos (e.g. `Learning-bro.svg`, BATTECHNO logos) |
| `src/assets/landing/illustrations/` | Landing and trust/verification illustrations (e.g. `trust-verification.svg`, hero art) |

`IllustratedStatusLayout` already imports from those folders. Prefer pointing new DS surfaces at the same files rather than copying assets into this directory.
