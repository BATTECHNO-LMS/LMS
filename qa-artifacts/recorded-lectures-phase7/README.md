# Phase 7 artifacts

This folder holds QA evidence for Field Training Recorded Lectures.

No secrets are stored here. YouTube API keys, auth tokens, and production credentials must not be copied into these files.

## Files

- `authorization-matrix.md` — role / org / action matrix
- `security-notes.md` — IDOR, SSRF, XSS, progress forgery, secrets
- `test-results.md` — unit, Playwright, build, migration status
- `query-counts.md` — heartbeat and list query observations
- `performance.md` — measured vs NOT_MEASURED
- `defects.md` — found, fixed, remaining
